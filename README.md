# نقشه میدانی — نسخه ۰٫۲

اپ اندروید مستقل (بدون سرور) با Capacitor. رابط داخل `www/` است و کتابخانه‌ها با `esbuild` از پوشه‌ی `src/` به `www/vendor.js` بسته‌بندی می‌شوند (در `npm install` خودکار انجام می‌شود).

## قابلیت‌ها

- **نقشه**: گوگل، OSM، پایه‌ی شهرداری مشهد، نشان. درخواست تایل‌ها از لایه‌ی بومی اندروید انجام می‌شود (بدون محدودیت CORS/Referer) و تایل‌های دیده‌شده روی گوشی کش می‌شوند (حداکثر حدود ۹۰۰۰ تایل).
- **مختصات**: بالای صفحه عرض/طول جغرافیایی و UTM با زون (E و N) مرکز نقشه؛ لمس هر خط آن را کپی می‌کند. موقعیت GPS هم با UTM نمایش داده می‌شود.
- **GPS و قطب‌نما**: موقعیت زنده با دایره‌ی دقت، قطب‌نما با جبران کجی گوشی.
- **ثبت و ترسیم**: نقطه (در مرکز نقشه یا از GPS)، خط، چندضلعی با طول/مساحت/محیط، ضبط مسیر حرکت.
- **پروژه**: همه‌ی لایه‌ها، نقاط و ترسیمات داخل پروژه روی گوشی ذخیره می‌شوند (IndexedDB). چند پروژه، تغییر نام، رنگ و برچسب هر لایه، پشتیبان کامل به‌صورت فایل JSON.
- **ورودی فایل** (با حفظ مشخصات و لایه‌ها): KML، KMZ (پوشه‌ها ← لایه)، GeoJSON/JSON، GPX، Shapefile (zip یا فایل‌های جدا؛ .prj و .cpg؛ فارسی)، DXF (لایه‌ها و رنگ‌ها؛ LINE، ARC، POLYLINE، TEXT/MTEXT، CIRCLE، POINT).
- **ورودی نقاط**: txt، csv، tsv، xlsx/xls، pts، dat، xyz، asc و … با تشخیص خودکار جداکننده، ستون‌ها، درجه/UTM و ترتیب X/Y؛ پنجره‌ی تأیید ستون‌ها.
- **خروجی**: KML، KMZ، GeoJSON، GPX، DXF، Shapefile، CSV و Excel (با UTM یا هر زون دلخواه)، پشتیبان پروژه. فایل ساخته می‌شود و از منوی اشتراک‌گذاری اندروید ذخیره/ارسال می‌شود.
- **مسیریابی**: نشان (با کلید خودتان) ← OSRM ← خط مستقیم؛ سریع‌ترین/کوتاه‌ترین؛ هدایت لحظه‌ای با فاصله تا پیچ بعدی، خروج از مسیر و مسیریابی مجدد، صدای اختیاری.

## ساخت APK روی GitHub

1. همه‌ی فایل‌های این پروژه را در ریشه‌ی مخزن آپلود کنید (پوشه‌های `www` و `src` را با کشیدن و رها کردن؛ فایل‌های هم‌نام جایگزین می‌شوند).
2. فایل `.github/workflows/build-apk.yml` از قبل در مخزن هست و تغییری نکرده.
3. Actions ← Build APK ← Run workflow؛ بعد از چند دقیقه `fieldmap-debug-apk` را از Artifacts بگیرید.

## ساخت محلی

```bash
npm install            # کتابخانه‌ها را هم بسته‌بندی می‌کند
npx cap add android    # فقط بار اول؛ مجوزهای GPS را به AndroidManifest اضافه کنید
npx cap sync android
npx cap open android
```

## محدودیت‌ها

- DWG پشتیبانی نمی‌شود (به DXF تبدیل کنید). در DXF قوس‌های bulge، HATCH و بلاک‌ها (فقط به‌صورت نقطه) ساده‌سازی می‌شوند.
- مسیریابی جاده‌ای آفلاین ندارد؛ بدون اینترنت فقط «خط مستقیم + جهت و فاصله» کار می‌کند.
- ضبط مسیر فقط وقتی برنامه باز و صفحه روشن است کار می‌کند.
