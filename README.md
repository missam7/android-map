# نقشه میدانی — نسخه ۰٫۳

اپ اندروید مستقل (بدون سرور) با Capacitor. رابط داخل `www/` است و کتابخانه‌ها با `esbuild` از `src/` به `www/vendor.js` بسته‌بندی می‌شوند (در `npm install` خودکار).

## تازه در ۰٫۳

- **مختصات**: یا جغرافیایی یا UTM (با زون)، به انتخاب کاربر؛ همزمان نمایش داده نمی‌شوند. انتخاب روی نوار بالا ذخیره می‌شود و در GPS، پاپ‌آپ‌ها و فهرست عارضه‌ها هم اعمال می‌شود.
- **ثبت با نگه‌داشتن انگشت**: ۱ ثانیه روی هر جای نقشه نگه دارید تا همان‌جا نقطه ثبت شود (حلقه‌ی پیشرفت، لرزش، بازشدن پاپ‌آپ ویرایش). با حرکت انگشت یا دو انگشت لغو می‌شود.
- **نمادها**: ۱۰ نماد (دایره، مربع، مثلث، لوزی، ستاره، بعلاوه، ضربدر، سنجاق، پرچم، هدف) با رنگ و اندازه؛ پیش‌فرض نقاط جدید، نماد هر عارضه و نماد پیش‌فرض هر لایه. (برای لایه‌های بیش از ۱۵۰۰ نقطه برای سرعت فقط دایره رسم می‌شود.)
- **فهرست عارضه‌ها در پروژه**: هر لایه را باز کنید؛ جستجو، سپس زوم / ویرایش / حذف / مبدا / مقصد.
- **نقشه‌ها**: Google Terrain، ترافیک گوگل (نقشه و ماهواره)، CycleOSM، OpenRailwayMap؛ OpenRailwayMap به‌عنوان رویه‌ی شفاف با تنظیم شفافیت روی هر نقشه‌ای قابل نمایش است.
- **لایه‌های برداری**: استان‌ها، نواحی/واحدهای ثبتی، پلاک ثبتی، کاداستر (سحاک، نیازمند کوکی)؛ شهرستان‌ها، بخش‌ها، مناطق شهرداری مشهد (WFS شهرداری)؛ و «افزودن لایه‌ی دیگر» برای هر لایه‌ی سرور شهرداری (نواحی، محله‌ها، …).
- **پارسل مشهد**: روی نقشه‌ی پایه‌ی شهرداری مشهد با لمس نقشه پارسل و کد نوسازی نمایش داده می‌شود؛ ذخیره‌ی پارسل در پروژه، کپی کد، و باز کردن صفحه‌ی گزارش‌های شهرداری.
- **مسیریابی**: Google Routes API (ترافیک‌آگاه، سریع‌ترین/کوتاه‌ترین) ← OSRM ← خط مستقیم؛ دکمه‌ی «باز کردن در Google Maps» برای هدایت با ترافیک زنده؛ نشان از مسیریابی حذف شد.

## تنظیمات و کلیدها (تب «نقشه» ← ⚙)

کلیدها فقط روی گوشی ذخیره می‌شوند، نه داخل کد یا مخزن GitHub:

| مورد | برای چه | از کجا |
|---|---|---|
| کلید Google Maps Platform | مسیریابی ترافیک‌آگاه | پروژه‌ی گوگل‌کلاود با فعال بودن Routes API |
| توکن پارسل مشهد | انتخاب پارسل | مقدار `MASHHAD_API_KEY` در server.js قدیمی |
| کوکی سحاک | استان و نواحی ثبتی | هدر Cookie مرورگر واردشده به سحاک |
| کلید نشان | فقط دو لایه‌ی نقشه‌ی نشان | پنل نشان |

## ساخت APK روی GitHub

1. همه‌ی فایل‌های این پروژه را در ریشه‌ی مخزن آپلود کنید (پوشه‌های `www` و `src` را بکشید و رها کنید؛ فایل‌های هم‌نام جایگزین می‌شوند).
2. Actions ← Build APK ← Run workflow؛ `fieldmap-debug-apk` را از Artifacts بگیرید.

## ساخت محلی

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

## محدودیت‌ها

- گزارش‌های عرصه/پروانه/پایان‌کار شهرداری خودکار نیست: کد کپی می‌شود و صفحه‌ی رسمی باز می‌شود.
- سرورهای شهرداری مشهد و سحاک ممکن است با VPN روشن جواب ندهند.
- مسیریابی جاده‌ای آفلاین وجود ندارد؛ بدون اینترنت فقط خط مستقیم + فاصله و جهت.
- DWG پشتیبانی نمی‌شود. ضبط مسیر فقط وقتی صفحه روشن است کار می‌کند.
